# Simple Calculator

A small command-line calculator written in C.

## Compilation

```
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 calculator.c -o calculator
```

## Usage

```
./calculator made to Print a welcome line.
Display a menu.
Allow quitting with option 0
```

The program displays a menu, asks for a choice, then asks for two numbers
and prints the result.

```
Simple Calculator
1) Add
2) Subtract
3) Multiply
4) Divide
0) Quit
Choice: 0
bye!
```
